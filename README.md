# 🏥 Animal Hospital 3D

3D-ремейк Roblox Animal Hospital на Three.js с FPS-управлением от первого лица.

## 🎮 Управление
- **WASD** — движение (W=вперёд, S=назад)
- **Мышь** — обзор на 360°
- **Shift** — бег
- **F** — лечить выбранного пациента
- **R** — отклонить пациента
- **Esc** — отпустить курсор

## 🎯 Цель
Пройдите 6 смен. Лечите настоящих пациентов, а подозрительных — отклоняйте.
Пациент автоматически появляется в карточке при подходе (если есть прямая видимость).

## 🛠 Технологии
- **Three.js r160** — рендеринг 3D
- **Web Audio API** — синтезированные звуки
- **PointerLockControls** — FPS-камера
- **CanvasTexture** — все текстуры рисуются кодом

## 🏗 Особенности
- Полноценная больничная сцена: 4 кабинета с кушетками, стойка ресепшн, зона отдыха, вендинговый автомат, склад
- Двери на петлях — открываются при подходе
- NPC доктор Харлоу патрулирует коридоры
- Животные: зайчик, щенок, котёнок, медвежонок, лисёнок, панда, поросёнок (с уникальными моделями)
- Аномалии (20% шанс) с визуальными отличиями: красные глаза, аура, тёмное тело
- Пациенты идут от входа через регистратуру к кабинету
- Система коллизий — нельзя пройти сквозь стены
- Прямая видимость (LOS) — нельзя выбрать пациента сквозь стену

## 🚀 Запуск

### Вариант 1: Локальный сервер
```bash
python3 -m http.server 8091
```
Открой: `http://localhost:8091/HOSPITAL-FINAL-*.html`

### Вариант 2: Без сервера
Самодостаточный HTML уже включает весь JS — но `importmap` + ESM модули не работают с `file://`, нужен HTTP.

## 📁 Структура
- `game.js` — вся логика игры
- `animal-hospital.html` — шаблон (HTML + CSS)
- `vendor/` — Three.js и аддоны (локально)
- `HOSPITAL-FINAL-*.html` — самодостаточные сборки (готовы к запуску)
